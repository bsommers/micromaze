# MicroMaze

Top-down pixel wave-defense: protect the registers from Perring Parkway Pete's micro-mice. Price-scanner gun + Bawlz can grenades. Cruel manager Christopher is yelling. 16-bit / 32-bit art modes.

Scaffolded by `game-factory new --web`. Contracts live in `ARCHITECTURE.md`; build plan in `docs/plan.md`.

```sh
npm start          # game → http://127.0.0.1:4881/
npm run tracker    # swarm dashboard → http://192.168.1.245:4880/ (LAN 192.168.1.x + loopback)
npm run plan       # regenerate .tracker/plan.json + prompts from docs/swarm/SWARM.md
npm test
```
